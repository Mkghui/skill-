## 一、官方标准结构（默认走这一版）

`0.` 那份写得最直白：「所有视频生成功能，统一使用这套官方标准结构，无需自创格式，直接填空即可」。所以 `h3Format: "zh"`（默认）时，每一镜的 H3 提示词就是这五块：

```
全局设定：
主体：精准定义人物/物体核心特征
场景：固定环境、背景、场地信息
风格：统一画面质感、色调、光影
固定不变元素：全程不可改动的人物、穿搭、场景、画风
镜头方式：单镜头/固定镜头/缓慢运镜，禁止切镜
声音：环境声 + 说话人（有台词时）；无任何人声对白（无台词时）
字幕：无任何文字、水印、字幕。

0-2秒：画面：… / 人物动作：… / 镜头：… / 音效匹配：… / 衔接要求：…
2-5秒：（同上五小项）
5-8秒：（同上五小项）

稳定约束：…
```

三种时长按镜头实际秒数分段：8 秒镜头就是 `0-2秒 / 2-5秒 / 5-8秒`；4 秒镜头是 `0-2秒 / 2-3秒 / 3-4秒` 这类按比例切的段。门查的是**边界连续、首段从 0 起、末段收在镜头时长上**，标签段数必须 3。

五小项的含义（照标准原文）：

- **画面**：该时段的画面状态
- **人物动作**：初始微动 / 核心可控动态动作 / 减速收尾定格
- **镜头**：初始镜头状态 / 对应运镜微调 / 镜头归位稳定停驻
- **音效匹配**：该时段专属环境音效，音量轻柔自然
- **衔接要求**：从静止平稳启动 / 动作连贯匀速 / 末端减速平稳定格

**一句话概括这份标准的脾气：一个镜头只做一件事，全程匀速、无突变、无新增**。稳定约束那一句固定写「全程保持人物外貌、发型、服装、场景、色调、画风完全一致……无新增人物、无多余物体、无场景跳变」。脚本 `fix` 在缺这一块时会补上模板原文。

### 有台词的镜头怎么填「声音」

模板的默认值是「环境声/无声，无任何人声」，但漫剧的台词要发给 TTS。本项目的写法（仍是那五行，不新增字段）：

```
声音：夜风穿过檐角的环境声 + 门外男子压低的说话声（C04，三十余岁男声，沙哑、带火气，画外音，台词：「……」），无其他对白。
```

字幕行永远保持「无任何文字、水印、字幕」——台词走配音，不烧进画面。

## 一之二、动作镜另有一份标准

打斗 / 施法 / 飞行 / 炼丹 / 突破 这类镜头，除了下面的通用规则，还要按 `h3-action-standard.md` 的五块写法（场景设定 + 主体与动作 + 特效与视觉 + 运镜与节奏 + 音效）补足力因果链、特效与具体声响。镜头标 `actionShot: true` 才会被 `h3-action` 门逐条查。

## 二、五种模式与各自的坑

标准里每个文件末尾都写了「新手避坑点」，这些就是 `h3-mode-align` 门要拦的东西：

| 模式 | 什么时候用 | 提示词里必须写明 | 避坑点（写错就崩） |
| --- | --- | --- | --- |
| **T2VA** | 无图可锁，纯文字原创（闪回、氛围镜） | 无需对齐句 | 无原图参考，控画面全靠分段小动作，别塞复杂多动作 |
| **I2VA** | 一张图作首帧，从该画面动起来 | 从**首帧 / 原图**静态画面启动，镜头写法要「严格贴合首帧画面」 | 只能细微微动；写奔跑、转身、跳跃、抬手这类大动作，百分百人物崩坏、画面撕裂 |
| **FL2VA** | 首帧 + 尾帧，补中间过渡（漫剧转场、动作切换的核心） | 首帧起步、**尾帧**收束，中间逐步收敛 | 首尾差异越小越丝滑；「室内转室外、站姿转坐姿、正面转背面」这类跨维度差异直接补帧错乱 |
| **L2VA** | 只给一张尾帧图，反推前置状态 | 最终收敛到**尾帧** | 前置状态必须可信 |
| **R2VA** | 多张参考图（人物身份 + 场景 + 风格），IP 统一、批量出片 | 每张**参考图**的唯一职责与保留项 | 禁止混搭古风/写实/二次元的不同风格参考图，风格冲突直接质感混乱、人物崩坏 |

`h3-refs` 门另查：`Picture 1 / Picture 2 …` 编号必须从 1 连续；I2VA 必须有 Picture 1；FL2VA 必须有 Picture 1（首帧）+ Picture 2（尾帧）；每张图的职责任务必须写清（「锁人物身份与服饰」/「锁环境与色调」/「本镜首帧」）。

## 三、英文适配版（`h3Format: "zh-en" | "en3"`）

标准给英文版两个合法形态，脚本两种都收：

**A. 模板镜像版**（`0.` 的英文通用模板 / `1.`–`4.` 的英文适配版）——与中文一一对应：

```
Global setting:
Subject: … / Scene: … / Style: … / Fixed elements: … / Camera movement: … / Sound: … / Subtitles: no text, watermarks or captions.
0-2s: Visual: … / Character action: … / Camera: … / Sound matching: … / Transition: …
2-5s: …
5-8s: …
Stability constraints: …
```

**B. 三字段专业版**（`5.` 的最终提示词格式）——字段之间空一行，必须严格这三个：

```
integrated_multimodal_description: [Shot 1] …
overall_soundscape: …
non_diegetic_music: …
```

B 版的硬规则（`h3-mode-align` / `h3-length` 门查）：

- 首镜不写时间戳；第二镜起用严格递增的切点：`[Shot 2] At 00:03.500, the camera cuts to…`
- **I2VA 的第一行必须逐字是**：`For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`
- **FL2VA / L2VA 的第一行必须逐字是**：`How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.`（N 与 S.SS 换成真实值，两位小数）
- T2VA / R2VA 不加对齐句；R2VA 要在开场写清参考分工
- 声音分三层：对白/画内音乐写进时间线，`overall_soundscape` 写 1–4 句环境声，`non_diegetic_music` 写 1–3 句配乐（没有就 `N/A`）
- 动作必须写成因果链：驱动力/意图 → 身体启动 → 接触与受力 → 惯性/阻力/重力 → 次级运动 → 减速与稳定
- 表演写成：情绪起点 → 触发事件 → 微表情变化 → 眼神目标 → 身体反应 → 情绪落点
- **整段英文提示词不超过 7000 字符**；超了先删重复画质词与同义风格词，绝不删对齐句、对白、关键动作、参考职责
- 画质增强词（哈苏 X2D / 8K / 电影感）只在写实、电影、广告、时尚类风格里启用，动画类别硬套

## 四、落到 manju.json

| 字段 | 写什么 |
| --- | --- |
| `params.h3Format` | `zh`（默认，官方标准结构）/ `zh-en`（加英文镜像版）/ `en3`（英文三字段专业版） |
| `shots[].mode` | `T2VA` / `I2VA` / `FL2VA` / `L2VA` / `R2VA`，脚本会把 `I2V` 这类简写归一化 |
| `shots[].refs` | `{"Picture 1": "C01 人物资产卡（身份与服饰）", "Picture 2": "S01 场景图（环境与色调）"}` |
| `shots[].h3.zh` | 官方标准结构（默认必须有） |
| `shots[].h3.en` | 英文版，`h3Format` 为 `zh-en` / `en3` 时必须有 |
