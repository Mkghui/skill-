# Z-Image（文生图）提示词标准

本文件是 `E:\2.漫剧制作\提示词\1.z-image(文生图)\` 五个 docx 的提炼，脚本里的 Z-Image 三道路由门（`zimage-structure` / `zimage-asset` / `zimage-microexpr`）按这里执行。

## 一、结构：主体 + 细节 + 风格 + 画面质量

- **主体与动作**：年龄、性别、肤色、发型、动作姿态、表情
- **细节与服饰**：服装款式、颜色、材质、妆容、配饰
- **场景与光影**：环境、光线来源与方向、光影效果
- **风格与画质**：写实 / 插画 / 厚涂 / 工笔 / 水墨 / 国风 / 二次元 + 高清 / 8K / 电影感

硬规则（`zimage-structure`）：提示词必须出现画质词与风格词；低于 40 字直接拦；低于 80 字提示「细节可以再具体」；**没写画幅只警告不出错**——场景类标准里的示例确实有不带画幅的，但漫剧要跨镜一致，建议每张都写横版 16:9 或竖版 9:16。

## 二、人物：资产卡，不是单张肖像

漫剧靠人物资产卡跨镜锁脸，所以人物提示词必须写成资产卡版式（来源：`zimage（修仙人物）提示词.docx`）：

```
横版16:9，超高清，古风仙侠女性角色资产卡片，真人质感与精致插画融合风格。
画面左侧为正面半身大头照（…五官与神态…），
画面右侧水平并排3张全身立绘：正面、45°侧面、背面。
（服饰：…款式/颜色/材质/配饰…）
纯白背景，影棚级柔和布光，自然垂手站姿，高分辨率，电影级质感。
```

- 必须含「三视图 / 立绘 / 大头照 / 角色资产卡片」之一（`zimage-asset` 拦）
- 必须指定纯白背景（否则抠图与资产统一无从谈起，只警告）
- 只给背影或剪影的角色同样要出资产卡，写清「不露正脸 / 面部隐于逆光」，三视图改成「背影、45°侧背、纯侧面」

## 三、场景：按近景 / 中景 / 远景分层，且必须写光

来源：`zimage（修仙场景）提示词.docx` 的写法是「近景是……中景为……远景是……」，再叠加色调、镜头语言、画幅：

```
东方修仙世界，云海之巅的恢宏剑修宗门…
近景是刻满古老符文的巨大石门，中景为宗门广场与渺小修士，远景是若隐若现的连绵群峰。
清晨时分，紫气东来，金色日光穿透云层…
空灵神圣，气势恢宏，国风仙侠概念艺术，水墨与数字绘景结合，电影级构图，超精细，
体积云，丁达尔光，宽银幕，16:9
```

`zimage-asset` 对场景只查一件事：**有没有写光**（光影 / 光线 / 体积光 / 丁达尔 / 晨光 / 烛光 / 月光 / 天光 / 布光）。场景资产的成败在光，不写光等于交半张图。

## 四、微表情：拆成肌肉变化 + 权重 + 反向约束

来源：`zimage（人物微表情）提示词.docx`。三条要点：

1. **拆细节不写情绪词**：不写「悲伤」，写「上眼睑下垂遮住虹膜上三分之一、下眼睑紧绷、眉尾向下、目光看向左下方」。
2. **带权重**：括号 `（1.6）` 或冒号 `上眼睑下垂:1.6`，两种写法标准里都用，脚本两种都认。
3. **带反向约束**：标准里每条情绪都跟一句「无泪流满面，无张嘴，无眼睛睁大」这类否定项，把模型的自由度收窄。

标准里可直接复用的条目（按情绪）：

| 情绪 | 提示词 |
| --- | --- |
| 压抑克制的悲伤 | 上眼睑下垂遮住虹膜上三分之一（1.6），下眼睑紧绷（1.9），眉头向上眉尾向下形成八字眉（1.7），目光向下看向左下方（1.5），眼周皮肤微微泛红（1.4），嘴角紧闭微微下垂，无泪流满面，无张嘴，无眼睛睁大。 |
| 伤感 / 委屈 | 眼尾泛红，眉心松又拧，嘴角下压，视线滑开，眼眶泛红，睫毛湿润，鼻尖发红，嘴唇微颤，泪光微闪。 |
| 真诚喜悦的微笑 | 嘴角自然上扬（1.3），脸颊抬起推动下眼睑（1.4），眼角有柔和的鱼尾纹（1.8），瞳孔略微放大（1.2），眼神温暖直视（1.6），眉毛舒展微微抬起，无强迫微笑，非卡通风格。 |
| 真实惊讶瞬间 | 眼睛完全张开露出整个虹膜（1.6），上下都能看到少量眼白（1.5），眉毛高高抬起形成拱形（1.7），额头出现水平皱纹，嘴巴微微张开呈 O 形（1.4），瞳孔放大（1.3），目光固定向前，无闭着嘴，无眉头紧锁，非卡通风格。 |
| 温柔深情的注视 | 眼睛自然放松微微半睁（1.3），瞳孔略微放大（1.5），眼睛里反射着柔和暖光（1.7），下眼睑微微隆起（1.4），眉毛自然舒展，嘴角紧闭带着一丝上扬，柔和黄金时刻光线，浅景深，无凶狠凝视，无眉头紧锁。 |
| 坚定（男性） | 眉头下压（1.6），眼睑收紧（1.5），嘴唇绷紧（1.4），嘴唇紧闭（1.3），锐利高光，眼神直视，无柔和感。 |
| 强装冷淡 | 眼皮半垂，嘴角拉平，眼神保持距离，下巴微收。 |
| 欲言又止 | 唇微张，眼神停住又移开，手指轻敲衣角。 |
| 心虚躲闪 | 视线频繁扫向门口或地面，笑意提前出现。 |
| 冷笑反击 | 眉眼轻挑，嘴角只抬一边，停顿一秒再开口。 |
| 破防瞬间 | 瞳孔轻颤，鼻翼发酸，眼泪打转却不落。 |
| 微醺 / 慵懒 | 眼尾轻挑带慵懒笑意，细碎睫毛轻颤，脸颊自然的红晕，迷离眼神。 |

**中英混写可以提命中率**：`dewy skin`（水光肌）、`dimples`（梨涡）这类英文词能触发不同理解维度。

脚本侧：`characters[].expr[]` 每条都要带权重（`zimage-microexpr` 拦）；镜头节拍里出现情绪词而这个镜头的角色一条微表情都没登记，会给一条警告。

## 五、落到 manju.json

| 位置 | 写什么 |
| --- | --- |
| `characters[].zImage.prompt` | 人物资产卡（资产版式 + 纯白背景 + 画幅 + 画质） |
| `characters[].expr[]` | 该角色会用到的微表情条目（`{emotion, prompt}`） |
| `scenes[].zImage.prompt` | 场景环境图（分层 + 光影 + 色调 + 画幅 + 画质） |
| `props[].zImage.prompt` | 关键道具 / 武器 / 符箓 / 秘籍——按器物白描五要素写，见 `z-image-props-standard.md`（`zimage-prop` 门查材质、光效、承载、具象） |
| `shots[].zImage.prompt` | 该镜的**首帧画面**（有动作、表情、构图的镜头必须单独写首帧） |

`shots[].zImage.negative` 可选：标准里没提负面提示词，ComfyUI 节点有负面框时才填。
