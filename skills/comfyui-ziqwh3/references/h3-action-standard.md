## 一、五块结构（场景 + 主体与动作 + 特效 + 运镜 + 音效）

这一份把动作镜拆成五块，用的是 H3 官方结构（场景 + 主体 + 动作 + 特效 + 运镜）在**动作题材**上的落地写法：

```
[场景设定]  暴雨将至的黄昏，悬浮于万丈云海之上的废弃仙门剑坪…
[主体与动作] 墨剑散仙（青年男性，白袍黑剑）被六名青冥剑修围杀，通过墨步错位、飞白剑痕反杀，
            动作快、险、飘、狠，无废动作。
[特效与视觉] 剑意爆发时，浓墨爆散、飞白剑痕、墨海撕卷、宣纸裂纹、冷青碎剑光交织…
[运镜与节奏] 一镜到底，镜头贴着飞剑高速切入，急停至主角腰侧，随后跟随墨步错位猛甩；
            撞击瞬间切慢动作（≤1.5秒），画面无闪烁跳帧。
[音效]      飞剑破空、剑锋碰撞、墨影炸散、剑碑断裂，配合高速战鼓与低频弦音。
```

**与 `0.minimaxH3 万能提示词` 的关系**：动作镜**仍然用万能模板的骨架**（全局设定 + 分时段 + 稳定约束），只是把上面五块的内容填进对应位置：

| 这份标准的块 | 填进万能模板的哪里 |
| --- | --- |
| 场景设定 | `全局设定：场景：…` |
| 主体与动作 | `全局设定：主体：…` + 各时段的`人物动作：` |
| 特效与视觉 | `全局设定：风格：…` + 各时段的`画面：` |
| 运镜与节奏 | `全局设定：镜头方式：…` + 各时段的`镜头：` |
| 音效 | `全局设定：声音：…` + 各时段的`音效匹配：` |

不要另起一套格式——万能模板的五行与三段不能省。

## 二、七类模板的动作与特效词汇表

| 类型 | 主体与动作 | 特效与视觉 |
| --- | --- | --- |
| **打斗** | 被围杀，靠身法错位与剑痕反杀，动作快、险、飘、狠，无废动作 | 剑意爆发：浓墨爆散、飞白剑痕、墨海撕卷、宣纸裂纹、冷青碎剑光 |
| **修炼** | 盘膝而坐，双手结印，随呼吸汇聚灵气，灵气凝为光茧 | 柔和粒子光晕；光茧破裂迸发金光，凤凰虚影；淡蓝 / 金 / 白 |
| **武器法宝** | 手持发光重剑（剑身流淌幽蓝寒光），挥剑划破空间 | 幽蓝冷光 + 黑白撕裂光痕，空间涟漪状扭曲，异次元紫红透光 |
| **境界提升** | 盘膝坐于云海，周身七彩霞光，身体虚化转为元神光体 | 霞光放射状迸发、道韵符文浮现消散、纯白光芒；七彩 / 纯白 / 金 |
| **炼丹成丹** | 手持丹炉盖缓缓揭开，丹药逐渐成型 | 炉内能量波动、丹光闪烁、丹药表面浮现古老符文；金 / 红 / 黑 |
| **大境界突破** | 立于天地间，金光包裹身体形成能量风暴 | 天空裂缝涌出能量、七彩祥云、山川河流被重塑、能量风暴 |
| **飞行** | 展开双臂升空，以高速姿态穿梭云海 | 流线型能量尾迹，随速度变长变亮；蓝 / 紫 / 白 |

每类都带「替换关键词指南」（场景 / 主体 / 特效三组），可跨题材复刻：仙侠 ↔ 赛博 ↔ 科幻。

## 三、四条调优建议（原文，全部进要点）

1. **明确时间分配**：H3 单次 4–15 秒，前 2 秒定场景，中间 5–8 秒展示动作与特效，最后 2 秒定格或收尾。→ 正好落在万能模板的 `0-2秒 / 2-5秒 / 5-8秒` 三段上。
2. **强化力因果链**：动作镜必须写出「**蓄力 → 传导 → 接触 → 反馈**」（如：压胯蓄力、剑锋斜劈、水面波纹炸开），否则动作「发飘」。
3. **控制特效密度**：特效词（飞白剑痕、粒子光晕）要与动作、场景结合，**堆砌会让画面混乱**。
4. **运镜配合节奏**：结合动作节奏写运镜（撞击瞬间慢动作、急速横移、镜头跟随），提升动感。

## 四、落到 manju.json 与门

镜头标 `actionShot: true` 后，`h3-action` 门逐条查：

| 查什么 | 判据 |
| --- | --- |
| **力因果链** | `h3.zh` 必须出现蓄力 / 发力 / 受力 / 传导 / 接触 / 惯性 / 反震 / 反馈 / 震荡 / 炸开 / 回弹 / 下沉 / 重心 之一 |
| **特效与视觉** | `h3.zh` 必须出现光效 / 粒子 / 流光 / 电弧 / 灵气 / 光晕 / 涟漪 / 波纹 / 霞光 / 符文 / 剑气 / 墨痕 / 气流 / 碎光 / 能量 之一 |
| **音效** | 「音效匹配：」行必须写到具体声响（破空 / 碰撞 / 炸散 / 轰鸣 / 碎裂 / 断裂 / 尖锐 / 嗡 / 闷响 / 刮擦 / 撞击 / 飞溅）之一，不能只写「音量轻柔」 |
| **节奏收尾**（警告） | 三段里应有一处 慢动作 / 减速 / 定格 / 收尾 / 缓 ——标准要求「撞击瞬间切慢动作 ≤1.5 秒」「最后 2 秒定格或收尾」 |
| **特效密度**（警告） | 全镜特效词超过 6 个 → 堆砌，画面会乱 |
| **图生图配合** | `qwenImage.prompt` 必须写景别（特写 / 近景 / 中景 / 全景 / 远景 / 大远景 / 微距）与动作词——动作戏的六件套是「风格 + 景别 + 场景 + 时间 + 动作 + 物理反馈」 |

另有一条**嗅探**（警告级）：镜头的节拍或摘要里出现 打斗 / 交手 / 厮杀 / 斗法 / 施法 / 结印 / 掐诀 / 御剑 / 剑气 / 法术 / 符箓 / 符纸 / 雷劫 / 渡劫 / 炼丹 / 丹炉 / 拳脚 / 掌风 / 御空 / 腾空 / 拔剑 / 出剑 / 剑阵 这些词，却没标 `actionShot`，会提示你按这份标准补写——标了才查，不标不拦。
