# Qwen-Image（图生图）提示词标准

本文件是 `E:\2.漫剧制作\提示词\2.qwen-image（图生图）\` 两个 docx 的提炼，脚本里的 `qwen-structure` 门按这里执行。

来源文件：

| 文件 | 定的是什么 |
| --- | --- |
| `qwen-image人与场景提示词.docx` | 图生图的两件事：**明确的修改指令** + **要保留的细节**；最多 10 张参考图；人像/场景/多图合成三类写法 |
| `qwen-image人物打斗攻击、施法、功法修炼、人物飞行、人物炼丹的提示词.docx` | 动作类提示词的六件套写法（风格 + 景别 + 场景 + 时间 + 动作 + 镜头/速度提示 + 画质） |

## 一、图生图的两条硬规则

`qwen-structure` 门只查三件事，缺一条就拦：

1. **修改指令**（要改什么）：`Replace / Extend / Transform / Composite / Dress / Convert / 替换 / 扩展 / 合成 / 改为 / 补全`
2. **保留从句**（不许改什么）：`Preserve / Keep / Maintain / Retain / unchanged / 保留 / 不变 / 维持 / 不改变`
   - 标准里每条示例都写全了保留项：面部、身份、发型、肤色、身形比例、姿态、机位、背景、光线方向、整体摄影风格
3. **参考图分工**：`image 1 / image 2 / reference image / 参考图 / 原图`——多图时必须说清哪张图负责什么

结论句是标准里的写法特征，值得照抄：`The final image should look like the person was originally photographed wearing this outfit.` / `with no obvious splicing traces`——一句「看起来本来就该是这样」，是融合类的成败句。

## 二、人像与服装（保留人物原貌）

标准给的三种模式：

- **换装**：换掉服装，保留面部/发型/肤色/身形/姿态/机位/背景，新衣服要跟着身体起褶、有缝线与阴影
- **换背景**：换环境，保留人物一切，**环境光与接触阴影要跟着新背景重算**，头发与衣服边缘要真实
- **多图组合换装**：image 1 人物 + image 2/3/4 衣服鞋 + image 5 配饰，各自保留颜色材质廓形细节

## 三、场景与背景

- **场景替换**：整张背景换掉，主体完全不变
- **场景扩展**：保留前景（人物、车）位置比例不变，往外扩背景，新背景的光线与阴影必须跟前景一致
- **风格转换**：保留原构图与透视（如建筑轮廓、空间布局），只换渲染方式（如改水墨：墨线勾轮廓 + 淡墨渲染 + 局部少量矿物色）

## 四、人像与场景融合

- **单人多景**：把 image 1 的人放进 image 2 的场景，调大小、位置、透视，光线色温跟场景对齐，保留五官与服装细节，不能有拼接痕迹
- **多人合框**：image 1/2/3 各一人，保留各自辨识特征，安排在同一空间里，用一致柔光与合理间距，成品要像一次拍出来的合影，**不像三张照片的拼贴**

## 五、动作戏：六件套

来源：`qwen-image人物打斗攻击、施法、功法修炼、人物飞行、人物炼丹的提示词.docx`。这一份是**中文**写法，与上一份的英文写法并存，项目里两种都合法（`qwen-structure` 门对中英文一视同仁）。结构固定为：

```
风格 + 景别 + 场景 + 时间 + 光照 + 动作 + 物理反馈 + 镜头/速度提示 + 画质
```

标准里的六类动作与各自的物理反馈词：

| 动作 | 提示词骨架（照抄结构，换内容） |
| --- | --- |
| 剑术 / 刀术近战 | 武侠风格，全景，古代荒野战场，白天，阳光明媚。白衣女侠与黑衣蒙面人持剑对峙，剑刃碰撞迸发火花，尘土飞扬，动态模糊强化速度感，8K超清，细节拉满。 |
| 拳脚 / 兵器肉搏 | 漫剧风格，中景，现代都市夜景，霓虹灯闪烁。特警与持刀歹徒近身搏斗，拳脚相交，气流搅动，衣料翻飞，镜头跟随动作平移，电影级光影，细节清晰。 |
| 暗器 / 远程 | 国风风格，远景，古代古城楼，黄昏。侠客侧身半蹲，甩出多枚飞刀，飞刀拖出银色流光轨迹，气流扰动，镜头俯拍，8K超清，细节拉满。 |
| 施法 / 气功 | 赛博朋克风格，特写，暗黑背景，紫色星云。法师双手结印，周身环绕蓝色电弧与紫色灵气波纹，动态粒子光效，镜头微距，8K超清，细节拉满。 |
| 功法 / 内力修炼 | 古风水墨风格，远景，高山云海，清晨薄雾。武者盘坐于悬崖石台，周身散发淡金色内力光晕，云雾随内力流动，留白构图，淡雅色调，8K超清。 |
| 飞行（仙侠 / 科幻） | 仙侠风格，全景，高空云海，黄昏逆光。剑客踏空腾跃，单脚点出气流涟漪，衣袂随风飘飞，仙气飘逸，镜头仰拍，8K超清，细节拉满。 |
| 炼丹（东方 / 赛博） | 古风工笔风格，中景，古代炼丹房，烛光摇曳。炼丹师手持拂尘，丹炉内火焰升腾，散发五彩霞光，烟雾缭绕，镜头微距，8K超清，细节拉满。 |

两条使用建议照抄标准：参数控制——末尾补「8K超清，细节拉满，动态模糊」；风格混搭——「赛博朋克 + 古风」这类可混搭。

## 六、落到 manju.json

| 位置 | 写什么 |
| --- | --- |
| `characters[].qwenEdit` | 角色级的换装 / 改装指令（`{prompt, note}`），全剧只用一次的那种改动放这里 |
| `shots[].qwenImage.prompt` | **每一镜的图生图指令**：在资产图上改出这一镜的动作 / 表情 / 姿态 / 合成，产出的就是 H3 的首帧 |
| `shots[].qwenImage.note` | 中文说明（标准里每条英文示例下面都配一句中文说明，照这个来） |

参考图最多 10 张，别浪费在重复的角色图上；动作镜头的六件套（风格 + 景别 + 场景 + 时间 + 动作 + 物理反馈）可以直接搬到 `shots[].qwenImage.prompt` 里用。
