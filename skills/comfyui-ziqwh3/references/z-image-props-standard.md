# Z-Image（文生图）器物资产标准：道具 / 武器 / 符箓 / 阵法 / 结界 / 功法秘籍

本文件提炼自 `E:\3.短剧\1.z-image(文生图)\zimage道具、武器、符箓、阵法、结界、修炼功法秘籍的提示词.docx`（该目录与 `E:\2.漫剧制作\提示词` 是同源标准目录，13 份共享文件字节一致，只多这一份与 `6.MiniMax H3打斗施法提示词.docx`）。脚本里的 `zimage-prop` 门按这里执行。

## 一、结构：白描五要素（主体 + 环境 + 光影 + 风格 + 细节）

这一份与 `z-image-standard.md`（人物 / 场景）的结构同源，但用**白描**手法，五要素的分工更硬：

| 要素 | 写什么 |
| --- | --- |
| **主体描写** | 画什么：外观、**材质**、颜色、细节；阵法 / 结界 / 功法则写形态与光效 |
| **环境背景** | 在哪里：场景氛围、空间关系、背景元素 |
| **光影氛围** | 光源方向、光效、色彩氛围 |
| **风格特征** | 像什么：艺术风格、视觉质感 |
| **质量修饰** | 画质、镜头、材质质感 |

三条使用建议照抄标准：

1. **细节具象化**：避免「好看」「厉害」这类抽象词，要用「黑金斧身」「紫色雷电纹路」「淡雅古风书房」这种具象描述
2. **光影与氛围**：明确光源（「柔和的暖光」「冷调光效」）和氛围（「压抑感强」「史诗感」）
3. **风格融合 + 篇幅**：可叠加风格（「东方玄幻风格 + 电影级光影」）；Z-Image 对长提示词理解好，**建议 100–200 字，核心主体放前面，细节修饰放后面**

## 二、四类资产的标准写法

### 1. 道具与武器（神器 / 剑器 / 辅助法宝）

标准示例：

```
盘古开天斧，黑金斧身，斧刃泛着幽蓝的混沌气流，斧面刻有古老的金色开天符文，斧柄缠绕着暗红色雷光。
斧头悬浮于水墨仙山之巅，背景是裂开的鸿蒙混沌，画面充满史诗感，电影级光影，8K超高清，写实摄影风格。

乾坤玉佩，温润的羊脂白玉质地，玉佩中央雕刻着金色的乾坤八卦图，玉佩边缘散发着柔和的青色灵光。
玉佩置于古朴的木制案台上，背景是淡雅的古风书房，柔和的暖光照射，微距镜头，宝物摄影风格，细节清晰。
```

写法要点：**材质 + 颜色 + 纹理/符文 + 光效/环绕物 → 承载物（悬浮于 / 置于）+ 背景 → 氛围 + 镜头 + 画质**。

### 2. 符箓

```
天机符笔绘制的「镇魔符」，符纸为泛黄的古旧宣纸，上面用朱砂和金粉绘制着繁复的红色符文，
符纸边缘散发着淡金色的微光。符纸平铺在青石古碑上，背景是幽暗的地下密室，烛光摇曳，
微距特写，复古工笔重彩风格，高对比度光影。
```

要点：**符纸材质（宣纸 / 羊皮卷）+ 绘制材料（朱砂、金粉、银墨）+ 符文形态 + 边缘光效 → 平铺 / 悬浮在什么上 → 微距特写 + 复古工笔 / 神秘玄幻风格**。

### 3. 阵法与结界

三类写法（平衡守护 / 大招 / 禁锢），共同点是「阵形铺展或悬空 + 符文流转 + 能量色 + 可含立于阵心的人物」：

```
金色八卦图腾铺展于青石地面，阴阳鱼在阵心缓慢旋转，八卦符号环绕四周，金色符文在地面流转。
一位剑修立于阵心，双手结印，周身散发着柔和的金色护体光晕，背景是淡雅的仙山云海，
广角镜头，强空间透视，东方玄幻风格，高清细节。

九宫格阵眼分布四周，金色锁链交织成灵力囚笼，层层亮起金色符文锁印。一名邪修被困在九宫阵心，
黑红魔气翻涌，背景是幽暗的废弃古庙，红黑冷色调，压抑感强，微距镜头，暗黑玄幻风格，高细节渲染。
```

**阵法的归属**：阵法 / 结界是**场景级资产**（有阵图铺地、可跨集复用）还是**可拿走的器物**（阵盘、符箓），决定它登记成 `scenes[]` 还是 `props[]`：

- 铺地 / 笼罩性的阵与结界 → 登记成 `scenes[]`，锚点写清阵形、符文走向与能量色
- 能攥在手里、能贴出去、能收起来的（阵盘、符箓、令牌） → 登记成 `props[]`

`zimage-asset` 门会在场景名或锚点命中「阵 / 结界 / 禁制 / 法域」时，要求该场景提示词必须写到符文 / 图腾 / 能量 / 光效 / 流转其中之一。

### 4. 修炼功法秘籍

```
宗门功法玉卷，半透明的青玉材质，玉卷上浮现着流动的金色功法文字，文字散发着柔和的青色光芒。
玉卷平放在古色古香的檀木书案上，背景是烛光摇曳的藏书阁，柔和的暖光照射，微距镜头，
宝物微距摄影风格，细节清晰。

天书残卷，残破的竹简材质，上面用朱砂书写着晦涩难懂的古老文字，竹简边缘燃烧着淡蓝色的幽冥火。
竹简散落在荒凉的远古废墟中，背景是破碎的石柱与残阳，微光折射，复古水墨画风格，高对比度，电影级画质。
```

要点：**载体材质（青玉卷 / 竹简 / 兽皮）+ 文字及其光效 + 边缘异火 → 平放的案台 / 散落的废墟 → 微距 + 宝物摄影或水墨风格**。

## 三、落到 manju.json 与门

| 位置 | 写法 |
| --- | --- |
| `props[]` | 道具 / 武器 / 符箓 / 阵盘 / 秘籍这类**能拿走、有特写、跨集出现**的器物 |
| `props[].note` | 必填：它承载什么剧情（写不出来的进 `scenes[].anchors`） |
| `props[].zImage.prompt` | 白描五要素：主体（**材质**）→ 承载与背景 → **光影** → 风格 → 画质 |
| `scenes[]` | 铺地 / 笼罩性的阵法与结界 |

`zimage-prop` 门（新增）逐条查：

1. **材质**：提示词必须出现材质词（玉 / 木 / 竹 / 纸 / 金 / 铁 / 石 / 布 / 绸 / 瓷 / 骨 / 铜 / 羊皮 / 宣纸 / 竹简 / 檀木 / 青铜 / 玄铁 / 黑金 / 琉璃 / 绢 / 银 / 紫金 …）
2. **光影**：必须出现光效词（灵光 / 微光 / 烛光 / 幽蓝 / 冷光 / 柔光 / 暖光 / 光影 / 发光 / 光晕 / 雷光 / 霞光 / 光效 / 辉光 / 折射 / 逆光 / 高光 …）
3. **承载**：必须交代它放在哪 / 悬浮在什么前（置于 / 悬浮 / 平铺 / 背景 / 白底 …）
4. **具象**：不得出现「好看 / 厉害 / 炫酷 / 帅气 / 漂亮 / 很棒」这类抽象词——标准明确点名
5. **叙事作用**：`note` 非空
6. **篇幅**：建议 100–200 字；低于 60 字算单薄，超过 240 字给警告（核心主体靠前、修饰靠后）
