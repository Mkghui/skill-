# Word 交付版式

`render` 把 manju.json 写成一份 `.docx`。**手写 OOXML 打包成 zip，零依赖**——不装 python-docx、不调 pandoc、不联网。

## 文件结构

```
《剧名》漫剧剧本
├── 封面信息表        剧名 / 原著 / 题材 / 规格 / 全剧画风 / 镜头数 / 人物·场景·道具 / 提示词格式
├── 交付说明          这份文件包含什么 + 投产三步（Z-Image 出资产 → Qwen-Image 改首帧 → H3 出视频）
├── 一、人物设定      每角色：定位 + 一致性锚点 + Z-Image 资产卡 + 微表情表 + Qwen-Image 换装
├── 二、场景设定      每场景：一致性锚点 + Z-Image 环境图
├── 三、道具设定      有 props 才出现
├── 四、分集剧本      每集：时长/镜数/场数 + 【钩子】 + 逐场节拍流（动作行 + 角色（语气）：台词）+ 【悬念】
└── 五、分镜提示词    每镜：摘要 + 运镜/人物/道具 + 参考图分工
                       ① Z-Image 文生图（首帧）
                       ② Qwen-Image 图生图（在资产图上做动作/换装/融合）
                       ③ MiniMax H3 图生视频（中文落地版）
                       ④ MiniMax H3 英文适配版（h3Format 带 en 时才有）
```

## 两种交付形态

| 命令 | 出什么 |
| --- | --- |
| `render <spec> --docx <基名>` | 一份**三段合一稿**：五章齐备（人物 / 场景 / 道具 / 分集剧本 / 逐镜提示词） |
| `render <spec> --split --docx <基名>` | 四份：三段合一稿 + `①Z-Image文生图`（人物 / 场景 / 道具 / 逐镜首帧）+ `②Qwen-Image图生图`（逐镜图生图指令）+ `③MiniMaxH3图生视频`（逐镜 H3 提示词） |
| `render <spec> --scope z\|q\|h3` | 只要某一个模型的一份稿 |

分模型稿只装自己那一段提示词（另两段在合并稿里），交付说明会指明配套文件；三种稿共用同一套版式。

## 版式

| 元素 | 样式 |
| --- | --- |
| 文档标题 | 微软雅黑 二号加粗居中；副标题 12pt 灰 |
| 一级标题 | 微软雅黑 三号加粗，深蓝 `1F4E79` + 下边框；**挂 Heading 1 大纲级别**，Word 导航窗格与目录都能用 |
| 二 / 三级标题 | 微软雅黑 四号 / 小四加粗，同样挂大纲级别 |
| 正文与动作节拍 | 宋体 五号，行距 1.3 |
| 台词行 | 宋体 五号，左缩进 0.74cm，角色名加粗：`顾清（内心独白，极轻的气声）：……` |
| 【钩子】【悬念】 | 微软雅黑 五号加粗，暗红 `C00000` |
| **提示词块** | Consolas + 宋体 五号，浅灰底 `F4F5F7`，左侧灰边线，左缩进 0.35cm；整块可一次性选中复制 |
| 说明 / 元信息 | 宋体 小五，灰色 `595959` |

## 纸型：默认 A4 横排

剧本是拿来对着屏幕抄提示词的，所以**默认 A4 横排**（297 × 210 mm）——一行能放下更长的提示词，段落换行少、复制更省事。版心宽度约 14.0 cm，两张表（封面信息表、微表情表）都按横排版心定宽，不会溢出。

要竖排加 `--page portrait`；两种纸型的字号、缩进、配色完全一致，只有页宽与表格宽度跟着变。

## 三条排版规矩

1. **提示词是等宽灰底整块**，与正文视觉上分明——Word 里三击选中整段，直接粘进 ComfyUI 节点，不会带上正文格式的麻烦。
2. **多行提示词用段内换行（`<w:br/>`）而不是拆成多个段落**：H3 的分时段、Z-Image 的分层描述在一格里保持完整，复制时不丢行。
3. **中文与 ASCII 混排不用空格补位**：中英之间的空隙交给 Word 的自动间距，手写空格会让复制到节点里的提示词多出脏字符。

## 改版式只改一个地方

`scripts/ziqwh3.mjs` 里的 `stylesXml()`（字号、字体、配色、缩进）与 `buildBody()`（章节顺序、每章放什么）。改完跑 `node scripts/selftest.mjs`，它会验证 docx 仍然是合法 zip 且关键字符串都在。
