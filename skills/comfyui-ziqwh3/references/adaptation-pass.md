# 小说 → 漫剧剧本：怎么写

这一层是模型干的活：把小说正文读成「集 → 场 → 镜 → 节拍 → 台词」，同时把三类模型的提示词写出来。写完必须过 `validate`。

## 一、先定规格，再动笔

四件事先拍板，写进 `params`：

1. **集数与单集时长**：抖音/快手漫剧单集 1–2 分钟，别按电视剧的 40 分钟来。1 分钟 ≈ 8 镜 × 8 秒。
2. **题材与爽点**：仙侠重修、逆袭打脸、悬疑惊悚……题材决定钩子写法。
3. **画幅**：横版 16:9（平台横屏）/ 竖版 9:16（抖音竖屏），全剧统一。
4. **`visualStyle`**：全剧统一画风一句话，写死。跨镜一致性靠它加资产卡两条腿，缺一条就飘。

## 二、分集：一集一个钩子 + 一个悬念

- 小说章节对不上集数：一章常能出 2–4 集，也可能几章合成一集。**按「一个冲突回合」切，不按章节切。**
- 每集必须两头硬：`hook` 落在首镜（冷开场就要给具象画面，不是交代背景），`suspense` 落在末镜。
- 结尾悬念是下一集的开场：写这一集的时候，就得知道下一集从哪一句接。
- 单集时长按 `minutesPerEpisode × 60` 秒做 ±15% 对账。写超了先砍动作节拍，写欠了补戏不注水——**加冲突不加寒暄**。

## 三、分场：场景能合就合

- 同一地点换时段算同一个 `scene`，时段写进 `time`（`夜` / `黄昏` / `清晨`），不是新场景。
- 场景是生成的资产，多一个场景就多一套一致性的成本。小说里的卧室、耳房、柴房，能归成一个「顾家·西厢」就归。
- 每个场景都要登记 `anchors`（空间布局 + 固定光源 + 色调），它是场景资产的锚点。

## 四、分镜：一个镜头只做一件事，8 秒

- 默认 8 秒一镜（H3 的 4–15 秒内）。**一镜 = 一个动作 + 一个反应**，别把「推门 + 回头 + 拔剑」塞进同一镜。
- 模式选择：从资产图动起来用 `I2VA`；锁人物身份 + 场景用 `R2VA`（漫剧量产的主力）；转场/动作切换用 `FL2VA`；纯闪回无图可锁用 `T2VA`。
- 运镜按 `minimax-h3-standard.md` 写「类型 + 幅度 + 速度 + 目标」，一镜只安排一个主运镜。

## 五、台词：单句一口气，谁的话像谁

- 单句 ≤ 35 字（门会拦），单镜台词总量 ≤ 秒数 × 5 字（8 秒镜 = 40 字封顶，超过口播塞不下），单镜最好不超过 2 句。
- 每句都要 `delivery`（语气）——TTS 和 H3 的表演提示都靠它。内心独白写成 `delivery: "内心独白，极轻的气声"`。
- 小说里的长对白必须拆：一段 80 字的对白，拆成 3 句、分到 3 镜里，中间用动作节拍隔开。
- **旁白不是免费的钱**：能演出来的别念出来。动作节拍能替代的台词，删。

## 六、漫剧特有的生成可行性（这一层最容易被忽略）

| 别写 | 改成 |
| --- | --- |
| 精巧动作（伸篙一挡、睫毛轻颤、指尖捻起一根头发） | 常见动作（推门、抬头、攥住、放下、转身半步） |
| 一个镜头里三个以上人物同框 | 拆镜：过肩、背景虚化、门缝剪影、只给背影 |
| 手与物体的复杂接触（穿针、结印六式、解绳结） | 抓握、托举、放下这类建立好的抓握关系 |
| 奔跑、跳跃、翻滚（在 I2VA 里） | 换成推近特写或切镜；I2VA 只做细微微动 |
| 大幅光影跳变（同一镜里从夜变日） | 拆成两镜，靠 FL2VA 补过渡 |
| 画面里的文字（族谱、木牌上的字） | 只写「刻着一个字」，别指望模型写对；真要字，用 H3 的画面文字规则明确写清 |

## 七、一致性锚点：逐字复用，不是每次重写

`characters[].anchors`、`scenes[].anchors` 写完之后，**每一镜的 `zImage.prompt` 都要逐字复用这段**，再加这一镜的动作、表情、构图。换个说法重写一遍，模型就换一张脸。

同一原则往上走：`visualStyle` 逐字进每张图与每段视频的「风格」栏；`params.aspectRatio` 逐字进每张图。

## 八、剧情逻辑自检清单（代码查不了的那一半）

代码门能查引用、时长、字数、编号，查不了戏。写完一集，照着过一遍：

1. **因果链**：每个结果都能指回前面一个动作。找不出因的果，就是硬转。
2. **动机一致**：人物做的事符合他登记在 `role` 与 `anchors` 里的身份性格。为推进剧情让人物做违心的事，是最常见的塌方。
3. **信息差**：观众知道什么、角色知道什么，分别列出来。反转必须前面埋过，不能靠最后一句解释。
4. **时间线**：同一集内日 / 夜 / 地点转换有没有交代。跳时间要有画面依据（灯灭了、鸡叫了、光影变了）。
5. **能力边界**：修仙 / 异能 / 金手指的规则要保持稳定。这一集能隔空取物，下一集就不能因为剧情需要拿不到。
6. **台词与画面不同义**：画面已经给的信息，台词不要再念一遍；台词要提供画面给不了的信息。
7. **钩子的诚实**：悬念要在下一集兑现，不能抛完就忘。抛了不还的钩子，掉的是观众的信任。
8. **原著的取舍留痕**：改了原著的设定或顺序，写进 `source` 之外的说明里（放在 `episodes[].title` 或场次锚点里都行），别悄悄改。
9. **一个人一集至少有一次主动选择**：主角全程被动挨打，观众不追。
10. **反派的合理**：反派的行为要有他自己的逻辑，不能只为了被打脸而存在。

前 7 条是硬伤，第 8–10 条是质量线。

## 九、四种常见的失败

- **赶集**：一集塞三个冲突，每镜都在交代。改法：砍到一条线，把别的留到下一集。
- **哑集**：一集全是动作没有台词，或全是台词没有画面（门会拦纯对白镜）。改法：动作节拍与台词交替。
- **像小说的剧本**：把小说句子原样搬进 `beats[].text`。改法：动作节拍写「能拍出来的画面」，心理活动一律转成动作或台词。
- **提示词复制粘贴**：一集里 8 镜的 `zImage.prompt` 一个样，只有最后一句话不同。改法：每镜单独写首帧，只有锚点和画风是复用的。
